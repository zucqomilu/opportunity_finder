# Utility Site Opportunity Finder

A personal, read-only research tool that mines a small set of
subreddits for posts expressing unmet product needs (e.g. "is there
a tool that...", "I wish there was an app for..."), to help identify
ideas for utility websites. Output is logged locally for manual
review — the bot does not post, comment, vote, or write to Reddit
in any way.
